# Calculadora React

Uma calculadora simples e funcional desenvolvida com React e Styled Components como parte de um desafio de front-end.

![Preview da calculadora](./preview.png)

## ✨ Funcionalidades

- Operações de soma, subtração, multiplicação e divisão
- Entrada de números com interface amigável
- Botão de limpar o visor
- Resultado exibido em tempo real na calculadora
- Layout responsivo e visual moderno

## 🛠️ Tecnologias

- React
- JavaScript
- Styled Components
- Create React App

## ▶️ Como executar

1. Clone o repositório
2. Acesse a pasta do projeto
3. Instale as dependências:

```bash
npm install
```

4. Inicie a aplicação:

```bash
npm start
```

5. Abra no navegador:

```text
http://localhost:3000
```

## 📦 Build de produção

Para gerar a versão otimizada para deploy:

```bash
npm run build
```
